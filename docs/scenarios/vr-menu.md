# Панели в шлеме

В шлеме интерфейс рисуется на виртуальном дисплее 1280×800, показывается его верхняя часть: меню 800 px, полоска 360 px, полоска с панелью 735 px.

| ID | Условия | Действие | Результат | Статус | Проверка | Тест |
