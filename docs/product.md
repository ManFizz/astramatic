# Продукт

## Зачем

Смотреть своё VR-видео и фото в Cardboard-шлеме с телефоном: файлы лежат на телефоне, на ПК или в Darkframe, управление взглядом и пультом, без снятия шлема. Ориентир по удобству — Play'a.

Приложение для одного пользователя, его телефона, шлема и пульта.

## Что не делаем

- Публикацию в магазин и всё, что нужно только для неё: регистрацию, монетизацию, онбординг, перевод на другие языки.
- Поддержку старых Android: `minSdk` 36.
- Шлемы с контроллерами и отслеживанием положения в пространстве: только поворот головы.
- Редактирование подключений в шлеме: там нечем набирать текст, это делается в 2D.

## Что умеет

### Источники

- Файлы на телефоне (видео и фото), выбор отдельного файла.
- Общие папки Windows по SMB: с проверкой подключения и переподключением после обрыва.
- AstraMatic на ПК: подключение по QR или ссылке, файлы по HTTP.
- Darkframe: коллекции и общая с Darkframe позиция просмотра.
- История: недавние на главной, полный список с удалением.

### Плеер

- Проекции: плоский экран, 180°, 360°, fisheye, EAC 360. Стерео: моно, бок о бок, сверху-снизу.
- Формат определяется по имени файла, ручной выбор запоминается для файла, есть формат по умолчанию для видео и фото.
- Перемотка, скорость, приближение, яркость, наклон и угол обзора, размер, расстояние и изгиб плоского экрана.
- Очередь из файлов папки: следующий и предыдущий, автопереход, повтор папки или файла, случайный порядок.
- Продолжение с места остановки.
- Фото и слайд-шоу с настраиваемым интервалом.
- Окружение: чёрное, кинозал, космос, закат или своя панорама из фото; подсветка кинозала цветом кадра.

### Интерфейс в шлеме

- Главная с файлами, полоска плеера, панели «Вид» и «Очередь» над ней.
- Точка взгляда, нажатие кнопкой шлема, пультом или задержкой взгляда.
- Меню растягивается за уголки и перетаскивается за ручку.
- Расстояние и размер меню настраиваются.

### Пульт и геймпад

- Любая кнопка или ось назначается на любое действие; одну ось можно назначить и на меню, и на просмотр.
- Стрелки и OK ходят по меню, колесо мыши его прокручивает.

### Шлем и трекинг

- Параметры шлема: линзы, поле зрения, искажения, положение телефона; в VR меняются на лету в калибровочной комнате.
- Рецентр, режим «лёжа», поправка ухода поворота по компасу.

### 2D-режим на телефоне

То же меню и плеер на обычном экране. Переключатель — экранная кнопка, только пальцем.

### Компаньон на ПК

- Раздаёт папки телефону, подключает телефон по QR.
- Пульт: воспроизведение, перемотка, рецентр, формат.
- Обзор папок и Darkframe, открытие файла на телефоне.

## Сравнение с Play'a

По [странице в SideQuest](https://sidequestvr.com/app/280/playa-vr-video-player) и [App Store](https://apps.apple.com/us/app/id1487295703). Версию для Cardboard по открытым источникам подтвердить не удалось, поэтому сравнение идёт с версиями для Quest и iOS.

| Возможность | Play'a | AstraMatic |
|---|---|---|
| Все стерео-форматы и проекции | есть | есть |
| Наклон, приближение, скорость, яркость | есть | есть |
| Контраст и насыщенность | есть | нет |
| Высота картинки | есть | нет, только наклон |
| SMB | на Quest | есть |
| DLNA | есть | нет |
| Очередь из папки, автопереход, случайный порядок | есть | есть |
| Свои плейлисты, «смотреть позже» | есть | нет |
| Повтор фрагмента A/B | есть | нет |
| Субтитры | есть | нет |

## Бэклог

Порядок обсуждается. Сначала — фундамент из плана ниже.

- Субтитры.
- Повтор фрагмента A/B.
- Контраст и насыщенность.
- Запоминать положение меню.
- Свои плейлисты и «смотреть позже».
- Звуковая дорожка: выбор.
- DLNA, если понадобится.

## План разработки

1. Документы и сценарии.
2. Проверка без телефона: логика, скриншоты, эмулятор.
3. Разделение `PlayerActivity`, `VrRenderer` и `VrMenu` под защитой тестов.
4. Дизайн-система: варианты стиля макетами, затем цвета, шрифты, иконки, размеры в градусах поля зрения.
5. Новые возможности из бэклога, каждая со сценарием и тестом.
